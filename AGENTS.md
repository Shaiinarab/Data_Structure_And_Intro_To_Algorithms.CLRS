## Algorithms Mini Homeworks

Python coursework collection where each exercise is a separate module and `main.py` is an interactive launcher.

## Where things are

- Exercise implementations: `mini_homeworks/`; launcher: `main.py`; centralized tests: `test_mini_homeworks.py`.

## Running and verifying

- Run the test suite from the repository root so module imports resolve against the local exercise package.

## Known pitfalls

- Preserve the independent exercise boundaries; do not couple homework modules through launcher-only state.
